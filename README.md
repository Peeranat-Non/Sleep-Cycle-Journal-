# นอนบ้าง — Sleep Cycle & Journal 🌙

เว็บแอปหน้าเดียว (Single Page Application) ที่ช่วยวางแผนเวลาเข้านอน–ตื่นนอนตามหลัก **Sleep Cycle** (รอบการนอน 90 นาทีต่อรอบ) พร้อมบันทึกไดอารี่การนอนประจำวัน เพื่อให้ตื่นมาสดชื่น ไม่งัวเงีย

## ✨ ฟีเจอร์หลัก

- **คำนวณรอบการนอน 2 โหมด**
  - **ตื่นกี่โมงดี** — กรอกเวลาที่จะเข้านอนตอนนี้ ระบบคำนวณเวลาตื่นที่เหมาะสม 4 ตัวเลือก (3, 4, 5, 6 รอบการนอน)
  - **เข้านอนกี่โมงดี** — กรอกเวลาที่ต้องการตื่น ระบบคำนวณเวลาเข้านอนย้อนกลับ 4 ตัวเลือกด้วยสูตรเดียวกัน
  - คำนวณจากรอบการนอน 90 นาที/รอบ + เวลาผล็อยหลับ 15 นาที พร้อมป้ายระดับสีตามความเหมาะสม (ขั้นต่ำ / พอใช้ / แนะนำ / เต็มอิ่ม)
- **Sleep Journal — บันทึกไดอารี่การนอนประจำวัน**
  - บันทึกเวลาเข้านอน–ตื่น (คำนวณชั่วโมงนอนอัตโนมัติ), คะแนนคุณภาพการนอน (1–5 ดาว), อารมณ์ตอนตื่น (อีโมจิ 5 แบบ), และโน้ตสั้น
  - มี validation ป้องกันค่าว่างและเวลาเข้านอน–ตื่นซ้ำกัน
  - ประวัติการบันทึกแสดงเป็นการ์ด พร้อมปุ่มลบรายการและปุ่ม "ล้างประวัติทั้งหมด"
- **จดจำข้อมูลอัตโนมัติ** ด้วย `localStorage` — ไม่ต้องกรอกซ้ำเมื่อเปิดเว็บใหม่
- **สถิติและแนวโน้ม** — กราฟสรุปแนวโน้มชั่วโมงนอน/คุณภาพการนอน และปฏิทินย้อนหลัง
- **อวาตารแสดงสถานะสุขภาพการนอน** ที่ผูกกับข้อมูลสถิติจริงแบบเรียลไทม์
- รองรับ **Light Mode / Dark Mode**
- ออกแบบให้ **responsive** ใช้งานได้ดีทั้งบนมือถือ, iPad และเดสก์ท็อป

## 🛠️ เทคโนโลยีที่ใช้

- [React 19](https://react.dev/) + TypeScript
- [Vite](https://vitejs.dev/) — build tool
- [Tailwind CSS 4](https://tailwindcss.com/) — styling
- [Recharts](https://recharts.org/) — กราฟแนวโน้มการนอน
- [Lucide React](https://lucide.dev/) — ไอคอน
- [Motion](https://motion.dev/) — แอนิเมชัน
- `localStorage` — เก็บข้อมูลฝั่งผู้ใช้ ไม่มี backend/ฐานข้อมูล

## 📁 โครงสร้างโปรเจกต์

```
src/
├── App.tsx                      # ตัวจัดการ state หลักของแอป
├── components/
│   ├── Header.tsx                # ส่วนหัวเว็บ
│   ├── SleepCycleCalculator.tsx  # คำนวณรอบการนอน (2 โหมด)
│   ├── SleepJournalForm.tsx      # ฟอร์มบันทึกไดอารี่การนอน
│   ├── SleepJournalHistory.tsx   # รายการประวัติการนอน
│   ├── SleepTrendsChart.tsx      # กราฟแนวโน้ม
│   ├── SleepTrendsAndCalendar.tsx# สถิติ/ปฏิทินย้อนหลัง
│   ├── SleepAvatar.tsx           # อวาตารแสดงสถานะสุขภาพการนอน
│   ├── MoodFaceIcon.tsx          # ไอคอนอารมณ์
│   ├── ThemeToggle.tsx           # สลับ Light/Dark mode
│   └── ConfirmModal.tsx          # โมดัลยืนยันก่อนลบ
├── context/ThemeContext.tsx      # จัดการธีม Light/Dark
├── constants/moods.ts            # ตัวเลือกอารมณ์ 5 แบบ
├── utils/sleepMath.ts            # สูตรคำนวณรอบการนอนและระยะเวลานอน
└── types.ts                      # TypeScript types
```

## 🚀 การติดตั้งและรันโปรเจกต์

```bash
# ติดตั้ง dependencies
npm install

# รันในโหมด development (http://localhost:3000)
npm run dev

# build สำหรับ production
npm run build

# preview ผลลัพธ์หลัง build
npm run preview
```

## 📱 การใช้งาน

1. เลือกโหมดคำนวณ "ตื่นกี่โมงดี" หรือ "เข้านอนกี่โมงดี" แล้วกรอกเวลา
2. ดูตัวเลือกเวลาที่แนะนำ 4 แบบ พร้อมป้ายบอกระดับความเหมาะสม
3. บันทึกการนอนประจำวันในฟอร์ม Sleep Journal ด้านล่าง แล้วกดปุ่ม "บันทึก"
4. ดูประวัติ แนวโน้ม และสถานะอวาตารสุขภาพการนอนของตัวเองย้อนหลังได้

## 📝 หมายเหตุ

โปรเจกต์นี้เป็นส่วนหนึ่งของงาน "สร้าง Web App ด้วย AI" พัฒนาด้วย Google AI Studio และ deploy ผ่าน Vercel ไม่มีระบบ backend, ฐานข้อมูล หรือการเชื่อมต่อ API ที่ต้องใช้คีย์ ข้อมูลทั้งหมดเก็บไว้ในเบราว์เซอร์ของผู้ใช้ผ่าน `localStorage` เท่านั้น
